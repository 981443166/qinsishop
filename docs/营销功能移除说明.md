# 营销功能移除说明（第一阶段）

> 目标：删除 App 内营销模块与入口，保留收银台原有优惠算价逻辑（不改金额、不改订单结构）。
> 修改文件：`assets/www/js/app.min.js`、`assets/www/html/tab/salesTab.html`

---

## 1. 删除了什么

### 1.1 营销菜单（19 项 + 1 个重复项）

从 `MenuConstant` 中删除：

| Key | 名称 |
|---|---|
| `TMSDETAIL` | 店铺信息（销货宝） |
| `TMSGOODSLIST` | 店铺商品 |
| `WECHATSELFORDER` | 微信自助下单 |
| `TMSORDER` | 店铺订单 |
| `CLIENTPOINT` | 积分 |
| `RECHARGE` | 充值/储值 |
| `COUPON` | 优惠券 |
| `MEMBERCARD` | 会员卡 |
| `WECHATMEMBERCARD` | 微信会员卡 |
| `WECHATPLATFORM` | 微信自动化经营 |
| `FLASHSALE` | 秒杀 |
| `PROMOTIONDISCOUNT` | 限时折扣 |
| `GOODSALBUM` | 商品相册 |
| `SMSERVICE` | 短信服务 |
| `INTELLIGENTCARD` | 商家名片 |
| `TMSDISTRIBUTION` | 分销 |
| `ECOMMERCE` | 电商 |
| `PASSENGERVOLUME` | 客流 |
| `MARKETINGCENTER` | 营销中心（两处重复定义） |

删除后 `menuType: marketingType / tmsShopType` 的活动菜单项为 0（保留 `AIASSISTANT`，它不属于营销模块）。

### 1.2 销售 Tab 的营销区块

`html/tab/salesTab.html` 中以下区块加 `ng-if="false"` 隐藏：

- 销货宝微商城 / 店铺订单卡片（原 78–98 行）
- 商品相册卡片（原 99–112 行）
- 电商 / 营销中心卡片（原 128–153 行）
- 电商权限分支里的“商家名片”单格（原 173 行）

“生意圈 / 秦丝商学院”保留。

---

## 2. 没有改什么

- **收银台算价**：优惠券、限时折扣、积分抵现、活动助手、智能短信的逻辑未改，历史订单仍按原金额渲染；
- **路由与模板**：营销页面文件仍存在，仅菜单与销售 Tab 入口被移除；通过深链或旧版本跳转仍可能打开（第二阶段处理）；
- **原生 SDK**：极光推送、微信/QQ 分享、友盟未移除；
- **客户档案里的营销字段**（券/积分/储值页签）未动。
