# 页面清理与包体精简说明

> 目标：清理首页/开单/客户详情的残留入口，收拾首页顶部间距，并压缩 APK 体积。
> 修改文件：`main.html`、`homePage/customFunction.html`、`sale/edit.html`、`client/detail.html`、`repack_apk.py`

---

## 1. 页面清理

| # | 页面 | 内容 | 处理 |
|---|---|---|---|
| 1 | 首页 | “销货宝-小程序订货”卡片（`TMSDETAIL`/`TMSORDER` 已删，点击会拿到 `undefined`） | 整块隐藏 |
| 2 | 开单页 | “智能短信提醒 / 客户购买提醒 / 客户购买日报”模块 | 整块隐藏 |
| 3 | 客户详情 | 会员卡号 | 隐藏 |
| 4 | 客户详情 | 公众号通知（已关注/粉丝详情/邀请关注/关联粉丝） | 两个分支都隐藏 |
| 5 | 客户详情 | 充值明细 | 隐藏 |
| 6 | 客户详情 | 优惠券（张数/入口） | 隐藏 |
| 7 | 客户详情 | 积分区块（当前积分/累计积分/积分明细） | 整块隐藏 |
| 8 | 首页 | Banner 删除后消息条顶到最上面 | 消息条补 `mt10` 间距 |

保留：客户折扣、欠款/余额、交易历史、地址、标签等业务字段。

## 2. 包体精简

| 项 | 处理 | 条目数 |
|---|---|---|
| Source Map | 删除全部 `*.map` | −13 |
| Native ABI | 只保留 `arm64-v8a`，删除 `armeabi-v7a / x86 / x86_64 / armeabi / mips / mips64` | −56 |

| 指标 | 修改前 | 修改后 | 变化 |
|---|---|---|---|
| APK 大小 | 96,458,120 B | 79,228,995 B | **−17.2 MB（−17.9%）** |
| ZIP 条目 | 3,273 | 3,207 | −66 |
| lib 条目 | 100+ | 45（仅 arm64） | — |

**字体未删除**：`notosansscnormal/bold` 被 jsPDF 用于 PDF 导出，`simhei` 被 CSS/打印使用，直接删除会导致导出/打印异常。后续如需再减，可做字体子集化（保留常用汉字），预计还能减 10–15MB。

## 3. 风险

- **arm64-only**：32 位设备（armeabi-v7a）和 x86 模拟器将无法安装（`INSTALL_FAILED_NO_MATCHING_ABIS`）；如需兼容旧设备，要再打一个 v7a 包。
- 客户详情的券/积分/储值字段隐藏后，历史数据仍在，只是不再展示入口。
