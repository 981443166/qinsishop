# 移除在线更新 — 修改说明

> 目标包：`com.qinsilk.appUniverse` 5.31.5（versionCode 53105031）
> 修改范围：仅 H5 资源（AngularJS 微应用），**未改动** dex、so、Manifest、资源表。
> 修改日期：2026-11-21

---

## 1. 目标

彻底停用 App 的两条在线更新链路，使已安装的包不会被远端替换：

| 链路 | 原行为 |
|---|---|
| **CodePush 热更新（H5 增量）** | 启动时 `checkForUpdate`，有更新则静默下载；手动“检查更新”走 `sync` 下载安装 |
| **原生整包更新（APK）** | 请求 `androidVersion*.json`，发现新版本弹窗，调 `updateApp.startUpdate` 下载安装 |
| **“检查更新”入口** | 我的 → 检查更新 |

---

---

## 3. 行为变化

| 场景 | 修改前 | 修改后 |
|---|---|---|
| App 启动 | 检查原生版本 → 检查 CodePush → 可能静默下载 | **不发起任何更新请求** |
| 我的 → 检查更新 | 弹“正在检查更新”，可下载安装 | 入口不显示；即使被调用也立即返回 |
| 首页/账号页自动检查 | 定时或进页面触发 | 立即返回 |
| 关于页热更新版本号 | 读取 CodePush 当前包 label | 显示 `ServerConfig.innerAppVersion`（原生版本） |
| 已下载未安装的 CodePush 包 | 下次启动可能安装 | 不再调用 `notifyApplicationReady`，不会安装 |
| 服务端版本 JSON | 会请求 `androidVersion*.json` | 不请求 |

**不受影响**：登录、盘点、销售、打印、扫码、定位、推送等业务功能；`updateApp` 插件仍存在于 dex 中，只是没有任何调用点。

---

## 4. 为什么没有直接删除原生插件

- CodePush 原生实现 `com.microsoft.cordova.CodePush` 与 `updateApp` 插件已编译进 dex，且插件注册信息不在可读的 `res/xml/config.xml` 中（资源路径被处理过）；
- 删 dex / 改 Manifest 属于二进制级修改，容易触发启动崩溃或签名校验问题，收益仅是“少一个不会执行的插件”；
- 当前做法已在**所有 JS 调用入口**短路，插件不会再被驱动，等价于功能移除，但风险最低、可一键回滚。

> 如需“物理移除”，需反编译 smali、移除 `CordovaPlugin` 注册与 `config.xml` 条目，属于独立高风险任务，本轮未做。

## 7. 影响与风险

1. **不再接收官方热修**：CodePush 与整包更新都被关闭，后续只能通过重新安装新 APK 升级；
2. **服务端若下发“必须更新”**：当前包内没有强制更新门禁（仅版本能力判断），不会阻断登录；若后端新增硬门禁，需要重新评估；
3. **回滚**：安装上一版搜索优化包或原始包即可恢复在线更新能力（均需卸载，签名不同）。
